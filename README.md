### ✈️ Intelligent Aviation Reliability & Flight Delay Prediction Platform

An end-to-end aviation data platform combining **AWS, PySpark, data engineering, analytics, and machine learning** to process flight data, engineer reliability features, analyze airline performance, and predict arrival delays.

### 📰 AI Newspaper Intelligence

A document-intelligence system that transforms a newspaper PDF into a searchable knowledge system using **RAG, semantic retrieval, Generative AI, and NLP**.

The system extracts newspaper content with PyMuPDF, creates semantic embeddings, retrieves relevant passages, generates grounded answers with Gemini, produces editorial-style briefs, and uses spaCy to identify entities such as people, organizations, locations, dates, and monetary values.

**Focus:** RAG · NLP · Semantic Search · Gemini · Sentence Transformers · spaCy
